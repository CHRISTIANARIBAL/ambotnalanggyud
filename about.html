About the Virtual Dissection and Preservation System

The Virtual Dissection and Preservation System is an educational tool designed to simulate basic biological laboratory procedures in a safe and digital environment.

This system focuses on specimen pinning and introductory dissection concepts(Frog), allowing students to understand proper techniques without the need for real biological samples.

🎯 System Objectives

  • Provide a virtual alternative to traditional specimen pinning and basic dissection procedures
  • Allow students to explore the anatomical structures of a frog through virtual dissection
  • Help students learn correct pin placement and proper handling techniques for preserved specimens
  • Reduce ethical, safety, and material concerns in biology laboratories
  • Enhance learning through interactive 3D visualization and guided simulations

🧪 System Scope and Limitations

This system is designed for educational simulation only. The preservation module is limited to pinning procedures and does not include chemical preservation or advanced dissection methods. The virtual preservation feature currently supports selected insect specimens, including butterflies, beetles, dragonflies, grasshoppers, and ants, which are commonly used in basic biology and entomology lessons.

For the dissection module, the system currently provides only a frog specimen for virtual dissection. This system demonstrates basic anatomical exploration and procedural steps intended to help students understand proper dissection techniques. Additional organisms and advanced dissection features are not included in the current version of the system.

The virtual dissection feature demonstrates anatomical exploration but should not be considered a replacement for hands-on laboratory experience.

💻 Technology Used

  • Visual Studio Code (VS Code) – as the primary code editor for developing, debugging, and managing the system
  • Blender – for creating, editing, animating, and exporting 3D specimen and organ models
  • Three.js – for real-time 3D visualization and interactive rendering
  • JavaScript – for system logic, interaction control, and animation handling
  • Tailwind CSS – for responsive user interface design and layout styling
  • WebGL – for hardware-accelerated 3D graphics rendering
  • EmailJS – for handling user suggestions and feedback submission
  • GitHub Pages – for hosting and deploying the web-based system

These tools were selected to ensure accessibility, performance, and ease of deployment, allowing the system to run entirely within a modern web browser.
